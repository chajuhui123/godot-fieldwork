학습 범위와 검수 기준

실행 엔진은 Godot 4.5.1입니다. 한국어 문서는 stable 버전이 갱신될 수 있어 수업별로 영어 4.5 기술 참고 링크도 제공합니다. 65개 수업의 개념·퀴즈·시작 코드·참고 코드·자동 검사 조건을 대조했습니다. 검수 기록: 2026년 11월 5일.

자동 검사는 표시된 실행 상태를 확인합니다. 코드의 모든 구현 과정, 셰이더 픽셀 결과, 실제 성능 향상이나 전체 주제 숙련도를 보장하지 않습니다. 웹에서 지원하지 않는 기능은 각 과제의 실행 범위에 관련 기초 실습임을 표시합니다.

이 검수는 프로젝트 내부 검수이며 Godot 문서팀의 검수·승인이 아닙니다.
